# 网页操作教程视频

把教程文案转成真实网页操作录屏，并制作字幕清晰、步骤准确的视频。不要生成或录制讲解人声。默认加入技能内置的低音量纯音乐；用户要求静音或没有配乐需求时关闭音乐。

## 工作流程

1. **确认素材。** 确认目标网址、教程目标、用户是否提供了教程文字、语言与视频规格，以及是否有音乐或品牌素材。未指定时，使用用户当前语言，输出 MP4（H.264/AAC），同时提供画面内字幕和独立 SRT 字幕文件。
2. **先准备教程文字，再录屏。** 用户提供了教程时，保留原意并核对步骤是否符合网页现状。没有教程文字时，先查看网页，整理成简洁、编号的步骤，再开始录制。每一步说明一个可见操作及其结果；不要编造页面功能、按钮名称或操作结果。只有关键步骤存在实质歧义时才提问，否则继续并把文案一并交付。
3. **安排操作和字幕。** 将每个教程步骤对应到具体页面状态和演示动作。字幕简短、易读，与对应操作同步；停留时间应足够阅读，且不要遮挡重要按钮或结果。
4. **打开并操作网页。** 使用可用的浏览器控制工具或 Playwright；需要登录时优先使用用户已登录的可见浏览器会话。环境中有 `playwright` 技能时，按其说明选择浏览器控制方式。优先使用可访问名称、角色和可见文本定位控件，重要操作后确认页面状态。录制期间保持视口尺寸和缩放比例一致。
5. **录制实际操作。** 录下真实网页界面，可以分段录制后再剪辑。使用 Playwright 录制视频时，关闭浏览器上下文以完成视频文件写入。不要用静态截图拼成幻灯片代替网页操作录屏。条件允许时保留清楚的鼠标指针和点击反馈，在重要结果处短暂停留。
6. **制作字幕、配乐和结尾。** 用 `scripts/make-srt.py` 根据录屏元数据生成 UTF-8 SRT，再按实际画面校准时间。用 `scripts/render-video.py` 将字幕烧录进 MP4 并混入默认纯音乐；用户要求静音时传 `--music none`，用户提供音乐时传 `--music 路径`。脚本默认让最后 1.2 秒缓慢淡到全黑，并让音乐同步淡出；可用 `--fade-out` 调整，设为 0 关闭。同时单独交付 SRT。关闭麦克风并移除网页、系统原声，音乐应音量克制、长度匹配视频。
7. **检查并交付。** 完整观看导出视频，确认操作与教程一致、字幕同步且清晰、没有意外人声或隐私信息、音频收尾自然，并确认结尾已缓慢变黑后才结束。交付 MP4、SRT、教程文案和音乐署名。

## 内置脚本

- `scripts/record-browser.mjs`：读取 JSON 操作计划，启动可见或后台浏览器、录制网页、按操作节点记录字幕时间。计划格式和示例见 [references/recording-plan.md](references/recording-plan.md)。
- `scripts/make-srt.py`：把录屏元数据中的字幕时间生成 UTF-8 SRT，可整体平移或限制结束时间。
- `scripts/render-video.py`：用 Pillow 生成字幕图层，支持中文自动换行，再由 FFmpeg 烧录字幕、混入背景音乐并导出 H.264/AAC MP4。默认使用 `assets/music/tutorial-loop.mp3`。

标准流程：

```bash
node scripts/record-browser.mjs plan.json
python3 scripts/make-srt.py raw/tutorial.json tutorial.srt
python3 scripts/render-video.py --video raw/tutorial.webm --srt tutorial.srt --output tutorial.mp4
```

运行脚本前先按 [录屏计划说明](references/recording-plan.md) 编写计划。脚本无法处理页面时，允许改用一次性 Playwright 脚本，但仍使用 `make-srt.py` 和 `render-video.py` 完成字幕与成片。

## 安全与访问

- 使用用户提供的登录会话；需要登录、MFA、多因素验证、同意授权或 CAPTCHA 时，让用户在浏览器中自行完成。不要要求用户把密码贴进教程，也不要把凭据或 Cookie 存进交付文件。
- 避免录入或展示个人、客户及账号数据。优先使用演示账号和安全的示例数据；必要时在交付前遮挡或模糊敏感信息。
- 制作教程不代表获得了对真实网站执行外部变更的授权。演示时不要发送、发布、购买、删除、邀请他人或提交有后果的更改。使用演示/测试环境，或停在最终确认操作之前并取得明确授权。
- 默认音乐为 Kevin MacLeod 的 "Meditation Impromptu 02"，纯钢琴曲，采用 CC BY 4.0。交付时要保留署名；完整信息见 `assets/music/LICENSE.txt`。用户提供其他音乐时，核实其目标用途许可。

## 默认交付

- 用户指定了保存位置时写入该位置；否则使用当前任务指定的输出目录。
- 源网页支持时优先使用 16:9、1080p；如用户指定平台或画幅，则按指定格式输出。
- 默认文件名为 `tutorial.mp4`、`tutorial.srt` 和 `tutorial.md`，并附一段简短署名：`Music: "Meditation Impromptu 02" by Kevin MacLeod (incompetech.com), licensed under CC BY 4.0.`
- 如果当前工具无法录制网页或无法烧录字幕，说明具体限制，并交付已完成的教程文字、录屏或独立字幕文件。
